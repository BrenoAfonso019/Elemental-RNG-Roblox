# Elemental RNG - Roblox

A Roblox RNG game project focused on random rolls, elemental rarities, progression, inventory and long-term gameplay systems.

## Project status

🚧 **In development**

The main game is currently being developed in Roblox Studio. The GitHub repository is being used to document the project's development, roadmap and future source-code organization.

## Current focus

- RNG / roll system
- Element rarity system
- Inventory and progression
- Persistent player progress
- Gameplay balancing
- UI and visual polish

## Development

Development is currently happening directly inside Roblox Studio. Source code and assets will be added to this repository as the project is organized for version control.
